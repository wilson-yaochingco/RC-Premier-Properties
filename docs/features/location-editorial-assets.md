# Location Editorial Image Sources

Status: Level 20 scenery set complete. Last reviewed 2026-09-12.

The 22 files under `frontend/public/images/locations/` are locally stored, reviewed
1920-pixel-wide derivatives of Wikimedia Commons photographs. They show recognizable
local scenery—roads, fields, waterways, streets, and a skyline—rather than churches,
government buildings, or generic property photography. They are editorial locality
context only: they are not listing media and do not imply that a property is near the
photographed scene.

Runtime attribution is visible beneath each detail-page image. The typed source of truth
is `frontend/src/features/locations/location-content.ts`. Each selected file was checked
against its Commons description for locality, subject, creator, and reuse terms, then
visually reviewed after download. The application serves only these local files and does
not hotlink to Commons.
