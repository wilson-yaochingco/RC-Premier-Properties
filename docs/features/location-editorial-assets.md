# Location Editorial Image Sources

The locality-detail scenery set is retired following removal of the location detail
routes. Twenty-one unreferenced JPEGs and their runtime content module were removed.
The one retained derivative and its original provenance are listed below; historical
sources for the removed files remain in Git history.

- `city-of-san-fernando.jpg` remains referenced by the isolated browser fixture API.

| Locality             | Local file                 | Scene                                   | Creator | Source                                                           | License                                                  |
| -------------------- | -------------------------- | --------------------------------------- | ------- | ---------------------------------------------------------------- | -------------------------------------------------------- |
| City of San Fernando | `city-of-san-fernando.jpg` | Mount Arayat across San Fernando fields | Shioan  | [Commons](https://commons.wikimedia.org/wiki/File:Mt_Arayat.JPG) | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0) |

Locations now uses four owner-approved images from the existing `photography-v1` property
set. These are illustrative home photographs, with subject-based alternative text and
no claim that they depict the tile's locality. The listing-gallery assignments remain
unchanged. See [production media](production-content-and-media.md) for editorial reuse.
